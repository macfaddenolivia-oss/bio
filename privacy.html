Privacy

Last updated: October 2026

This is a personal academic website. I don’t sell anything, use cookies, or ask you to create an account. Here’s what happens when you visit.

Visitor statistics

I use GoatCounter to see how many people visit this site and which pages they look at. GoatCounter is designed to respect privacy: it doesn’t use cookies, doesn’t store your IP address or set any tracking ID, and doesn’t follow you across other websites. It only records aggregate information, such as which page was viewed, the referring website, your browser and operating system, screen size, language, and approximate country. This data can’t be used to identify you. You can read GoatCounter’s privacy policy at https://www.goatcounter.com/help/privacy (opens in a new tab).

Hosting

This site is hosted on GitHub Pages. Like most web hosts, GitHub may log basic technical information, such as IP addresses, for security and operations. See GitHub’s privacy statement at https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement (opens in a new tab).

Links to other sites

Some links lead to other websites, such as LinkedIn, Northeastern University pages, and a Google feedback form. The link to my policy menu goes through TinyURL so I can see how many people visit it from this site. Those sites have their own privacy policies.

Email

If you email me, I’ll only use your message and address to reply to you.

Questions

If you have questions about this page, you can reach me through the Contact page.
